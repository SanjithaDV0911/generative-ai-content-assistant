# Generative AI Content Assistant — Mini Project

## Description
A mini web application concept that demonstrates how Generative AI can assist users in generating and refining content from prompts.

## Features
- Prompt-based content generation
- Social media caption generation
- Blog idea generation
- Professional email drafting
- Product description generation
- Simple text refinement

## Tech Stack
HTML, CSS, JavaScript, Generative AI Concepts

## How to Run
Open `index.html` in any modern web browser.

## Note
This is a frontend mini-project demonstrating the workflow and concept of a Generative AI content assistant. It does not call an external AI API.
